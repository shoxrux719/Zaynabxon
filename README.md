## Запуск

Нужен Node.js 22.12 или новее.

```sh

npm run dev -- --host 0.0.0.0 --port 5175 --strictPort
npm run build
```

## Заявки

Форма отправляет данные через `/api/lead` в отдельную Telegram-группу Зайнабхон. Бот: `@ZaynabSite_bot`. Серверные значения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` читаются из `.env` либо переменных окружения; в клиентский код они не попадают. `.env` исключён из Git и недоступен через Vite. При публикации на Vercel эти два значения нужно задать в окружении проекта; функция находится в `api/lead.mjs`.

Префикс +998 фиксирован. Остальные 9 цифр автоматически группируются как `90 123 45 67`; лишние цифры отбрасываются. Поддерживается вставка полного международного номера. Сервер повторно проверяет поля, ограничивает частоту запросов и возвращает успех только после подтверждения Telegram. Ошибки сохраняют введённые данные и предлагают прямую связь.

## Проверки и подготовка медиа

`npm test` проверяет маску, валидацию и обработчик заявок с изолированным Telegram-транспортом. Реальные сообщения в группу тесты не отправляют.

`scripts/prepare-media.py` повторно собирает WebP-превью и полные версии из предоставленных папок, удаляет точные повторы по хешу и подготавливает H.264-видео с постером. Для него нужны Pillow и imageio-ffmpeg. Исходные материалы не изменяются. Подготовленные файлы уже находятся в `public/assets/zaynabxon/work/`, поэтому для обычной сборки Python не требуется.
